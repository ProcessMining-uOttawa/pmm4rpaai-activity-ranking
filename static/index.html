PMM4RPAAI Activity Ranking

Load your process data, set up to three goals, and see which activities would contribute most to them if automated. The shortlist is the set of top-ranked activities that reaches your targets. All times are in minutes.

1Process data

Choose how to provide the data. Files are processed by this app on your own computer.

A CSV file with one row per activity execution: a case ID, an activity name, and a start and end time (or a duration).

Cost per execution is taken from the cost column where it has a value. Otherwise it is processing time × the hourly rate, using the default rate when a row has no rate.

A CSV file with one row per activity and its totals: activity, total_duration, total_cost, rework_duration.

Type the total processing time of the process and the time of each activity, in minutes. Executions (how many times the activity was performed) is optional, but needed for bot execution time and number of bots.

4Assess the shortlisted activities

Split each shortlisted activity into its tasks and give every task a value from 0 to 100 on each criterion: how much it stands in the way of automation (0 = no obstacle, 100 = complete obstacle). Uncertain values take three estimates: optimistic, likely and pessimistic. Each result is calculated for all three, giving the Low / Mid / High levels the simulation needs.

Criterion weights

The same six values drive three outputs. Each output has its own weights (in %, each column summing to 100), because what blocks automation is not always what makes a bot fail or run slowly.

weighted barrier W = Σ weight × value automation feasibility = max(0, 100 − W_feasibility) bot failure rate = lowest + (highest − lowest) × W_failure ÷ 100 bot time = task time × (lowest + (highest − lowest) × W_bot time ÷ 100)

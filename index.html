PMM4RPAAI Activity Ranking

Load an event log, set one or two goals, and see which activities would contribute most to them if automated. The shortlist is the set of top-ranked activities that reaches your targets.

1Event log

A CSV file with one row per activity execution: a case ID, an activity name, and a start and end time (or a duration). The file is read in your browser and isn’t uploaded anywhere.

2Goals

Choose one or two things you want to reduce, and set a target for each.

3Ranked activities

Each activity is assumed to be 100% automated. Its share of the total is therefore the reduction it would contribute, and the cumulative column shows the running total against your target.

Each activity is assumed to be 100% automated, so its estimated reduction equals its share of the total. Activities with zero recorded duration are treated as already automated and left out of the ranking.
